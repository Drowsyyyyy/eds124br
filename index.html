Repeats — Code Explanation

The purpose of my program is to animate a breakdancer who says “Let’s Dance!”, moves to the right, does a full flip, returns, changes size, and says goodbye — using repeat loops to keep the code concise.

The way my code works is: a repeat loop moves the dancer right 4 times (change x by 20 with a short wait each time); another repeat turns the dancer 36° ten times to complete a flip; another repeat moves left 4 times; and a final repeat shrinks the dancer in five steps. Each loop highlights how repetition automates repeated actions.

If I were to change a repeat — for example, doubling the “move right” loop from 4 to 8 — the dancer would travel twice as far before flipping. Reducing the flip loop from 10 to 5 would result in only a half rotation instead of a full flip.

Circle of Squares — Visualizing Nested Repeats

Tool: Snap (snap.berkeley.edu)  •  Concept focus: Nested repeat (inner/outer)  •  No variables, conditionals, or events beyond green flag.

Learning Objective

Students will see how an inner loop constructs one unit (a square) while the outer loop repeats and rotates that unit to produce a complex pattern. They will predict outputs when loop counts/angles change (e.g., 24 × 15° also totals 360°).

Program (Block Sequence)

  1. when green flag clicked
  2. go to x: 0 y: 0
  3. clear
  4. set pen size to 2
  5. (optional) set pen color to any
  6. pen down
  7. repeat 36
    1. repeat 4
      1. move 80 steps
      2. turn 90 degrees
    2. turn 10 degrees
  8. pen up

Required Explanations (ready to say)

  • The purpose of my program is… to draw a circular pattern made from many squares so students can see how a nested repeat builds a complex image from a simple shape.
  • My code works by using nested repeats in this part to… draw one square (inner loop, 4 sides at 90° each). It also uses nested repeats to place many copies around a circle (outer loop runs 36 times, turning 10° each time to total 360°).
  • If I were to change this nested repeat like this… change the inner loop to repeat 3 and turn 120°, the program would run differently: it would draw triangles instead of squares. Or keep squares but change the outer loop to repeat 24 with turn 15°; it still completes a circle, but shapes are spaced farther apart.

Change Analysis Examples

  • Inner loop: repeat 3 + turn 120° → ring of triangles.
  • Outer loop: repeat 24 + turn 15° → completes circle with wider spacing.
  • Side length: reduce move 80 → same layout with smaller shapes and more negative space.

Reflection (1–3 sentences)

Nested repeats let us scaffold complexity: the inner loop defines a shape; the outer loop controls placement and repetition. Small numeric changes produce predictable visual differences, supporting reasoning about iteration and angles.
